The question remains whether replacing sensitivity U-Net InstanceNorm with FP32 spatial moments and channels-last layout reduces final reconstruction quality. Each arm trains a 12-cascade VarNet for 50 epochs, using 18 reconstruction channels, four pools, full-resolution 256x256 sensitivity maps, compiled BF16 sensitivity/reconstruction U-Nets, batch size 16, Adam LR 0.001 and a step decrease at epoch 40. The same fixed R=8 grid mask is used in both arms. FFT shifts are unchanged. Both arms use the same current source snapshot; they differ only in sensitivity normalization/layout.

Data now uses the repository's `datasets=brain` manifest configuration: brain AXT2 only, tier S, 80 train volumes (1,222 energy-filtered slices), 40 validation volumes (609 slices), and 20 coil slots retaining all coils. The manifest resolves files under `/export/scratch/bkadota/fastmri_raw/brain/multicoil_{train,val}`. All selected train/val files are present. The larger tier L has 220 additional T2 training volumes absent from this machine; those are excluded. The 40 test volumes are excluded from both loaders and all evaluation.

The interval does not estimate uncertainty across arbitrary training seeds. No acceptable-loss margin is assumed; a non-significant difference is not proof of equivalence.
